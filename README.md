# Taleem Guide PK
Next.js 14 (App Router) + Tailwind CSS.

    npm install
    cp .env.example .env.local   # add your domain and AdSense ID
    npm run dev

Edit all content in `lib/data.js`. Ad units sit in `components/AdSlot.js`.
After AdSense approval, put your publisher line in `public/ads.txt`.
Add Privacy Policy, About and Contact pages before applying to AdSense.
